## 前端实现

- `studio-art.css`：全幅首页景观与文字遮罩、栏目插画、暖纸/深林配色、响应式排版和卡片细节。
- `studio-art.js`：仅向现有标题、空状态和功能卡挂载装饰图；不发起服务端控制请求。
- 主视觉优先加载，其余非首屏装饰采用延迟加载、异步解码和固定尺寸，减少布局跳动。
- 图片使用空 `alt` 与 `aria-hidden`；真实状态、表单、按钮和图表仍是可读可操作的 HTML。动态插画加载失败时隐藏图片，不遮住操作区。
- 保留已有元素 ID 与事件绑定，尊重减少动态效果的系统设置。
- 修正上传按钮文字对比度，以及自动化页旧深色卡片变量造成的说明文字过暗、留白过大。
