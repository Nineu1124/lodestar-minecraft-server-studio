# 2026-09-05 · 稳定性修复与工作台改版

## 界面

- 左侧实例切换与分组导航，替换拥挤的横向菜单。
- 缩小首页主视觉，让状态、启停和最近备份进入首屏。
- 统一暖纸色与深林色主题、图标、卡片、字体层级和表单。
- 增加最近日志、连接地址复制、维护提示与断线提示。
- 手机抽屉导航、键盘焦点样式与减少动画支持。
- 修复性能图柱形被严格 CSP 阻止的问题，未放宽页面安全策略。

## 核心修复

1. 端口监听不再等于实例归属；未知进程不会被误接管或停止。新启动记录结合 PID、创建标识及服务端路径校验。
2. 文件编辑绑定实例、路径和文件版本。切换实例清空旧会话；延迟返回的旧响应不能覆盖新实例。保存保留原文件历史、UTF-8 BOM 与 Windows 换行。
3. 世界备份先写临时文件，附加清单与 SHA-256，校验完成再发布。半成品不会显示为正常 ZIP。
4. 启动、停服、重启、备份、恢复共用实例维护锁；恢复排队时也不能启动。
5. 备份包含主世界、同名下界/末地目录，以及根目录中含 level.dat 的附加世界。
6. 中文下载文件名通过标准编码响应头发送。
7. Java 9+ 使用原生参数文件解析多参数行；Java 8 提供兼容处理，面板内存参数最后覆盖。
8. 写入操作要求明确有效的实例 ID，失效 ID 不再退回第一个实例。

另外：正版验证状态显示已修正；性能采样移至后端；在线备份等待保存确认及恢复自动保存确认，失败会显示维护提示。

## 升级注意

- 已运行的面板需要重启 Python 进程，再按 Ctrl+F5 刷新网页。若旧面板还托管游戏服，先用旧面板正常停服，再退出面板；不要强行结束 Java。
- 旧进程没有身份记录时会显示端口归属冲突。请从原控制台正常停服，再由新版面板启动。
- 旧 ZIP 保留且仍可下载，但缺少完成清单的备份不再自动恢复；需要人工核验。
- 备份不是完整服务端镜像。Mod、插件数据及非标准世界位置要另行检查备份范围。
- 备份回收站与恢复历史仍占磁盘空间，不会自动永久清空。
- 若在线备份提示未确认恢复自动保存，应检查控制台并执行 save-on；自定义日志格式不受识别时可正常停服后进行离线备份。
