# Minecraft 面板功能调研

Lodestar 的定位是“单台个人电脑上的本地服务端工作室”，因此参考成熟面板的服主管理能力，但不复制面向商业托管商的计费、节点售卖和多租户体系。

## 参考产品

| 产品 | 官方资料中突出的能力 | Lodestar 对应能力 |
| --- | --- | --- |
| [Crafty Controller](https://craftycontrol.com/) | 多实例、控制台、文件、配置、备份 | 多实例、实时控制台、安全文件管理、配置、备份与恢复 |
| [PufferPanel](https://docs.pufferpanel.com/en/2.x/about/about.html) | Web 管理、多服务端、模板 | ZIP 自动识别、一键推荐与自定义导入 |
| [MCSManager](https://docs.mcsmanager.com/) | 终端、文件管理、权限、分布式节点 | 本机终端和文件管理；刻意不开放远程节点与公网面板 |
| [Pterodactyl](https://pterodactyl-panel.mintlify.app/api/client/schedules) | 计划任务、备份、文件与启动配置 | 自动备份、定时重启、启动参数、备份恢复 |
| [AMP](https://www.cubecoders.com/AMP/TQ) | 内容管理、计划任务、文件、配置、统计与通知 | Mod/插件管理、计划、文件、可视化配置、性能采样 |

## 已吸收的本地面板能力

- 服务端生命周期：启动、正常停服、重启、失败进程结束、EULA 与启动前检查。
- 原始包导入：ZIP 安全检查、嵌套根目录、脚本/JAR/Forge 参数推断、Java 建议和解压进度。
- 运营：常驻命令库、玩家与名单、游戏规则、公告、实时日志。
- 内容与文件：Mod/插件启停回收、安全文件浏览、编辑历史、下载和上传。
- 数据安全：在线备份、保留策略、停服恢复、恢复前回滚副本。
- 可观测性：CPU/JVM/玩家采样、端口与磁盘检查、高信号日志、崩溃报告和自动原因归类。

## 有意不内置的托管商功能

- 计费、套餐、节点售卖和资源配额。
- 默认公网登录、多租户权限和分布式守护进程。
- 未经用户授权上传世界、日志或崩溃报告。

这些能力会扩大攻击面，也偏离“本机导入 ZIP 后一键开服”的核心场景。未来若增加局域网模式，应先加入账户、HTTPS、会话审计和细粒度授权。

## 需要外部服务的可选方向

- Modrinth / CurseForge 元数据、依赖与更新检查。
- Discord / Webhook 启停、崩溃和备份通知。
- S3 / SFTP 异地备份。
- RCON 管理非本机服务端。
