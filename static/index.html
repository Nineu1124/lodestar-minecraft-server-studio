    开源本地工具

    把复杂的整合包服，变成一件从容的事。

    Ripple Server Panel 是一个面向整合包服主的本地 Web 管理面板。

    v2.3.1
    ⌘

    多实例

    导入并切换不同服务端，自动识别常见加载器和启动文件。

    ›_

    网页控制台

    查看实时日志，发送任意 Minecraft 服务端指令。

    ◇

    可恢复 Mod 管理

    上传、启停和回收 Mod，不直接永久删除文件。

    ◴

    安全备份

    在线保存后压缩世界与关键玩家配置，并按数量轮换。

    ♙

    玩家权限

    白名单、OP、踢出与封禁操作集中处理。

    ◌

    游戏规则

    实时调整时间、天气、难度与常用 gamerule。

    ◐

    暖色双主题

    浅色陶土与深色炭火主题，可跟随系统或手动切换。

    按间隔备份世界，在每天固定时间正常重启。

    聚合 Java、崩溃报告和日志中的高信号错误。

    安全边界

    面板只监听 127.0.0.1，校验 Host 与 Origin，并限制可修改的配置路径。SakuraFRP 只映射 Minecraft 的游戏端口，切勿映射面板的 8765 端口。

    这是管理工具，不会自动解决 Mod 依赖或兼容性；更换 Mod 前建议先创建世界备份。

    选择包含 server.properties、服务端 JAR 或启动脚本的文件夹。面板不会复制整合包文件。
